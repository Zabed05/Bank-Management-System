Bank Management System

A simple console-based Bank Management System built using Java to practice Object-Oriented Programming (OOP) concepts.

Features

- Create Savings and Current Accounts
- Deposit Money
- Withdraw Money
- Check Account Balance
- Display All Accounts
- Delete an Account
- Automatic Account Number Generation

OOP Concepts Used

- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Classes & Objects

Technologies

- Java
- Java Collections ("ArrayList")
- Scanner (Console Input)

Project Structure

BankManagementSystem/
│
├── Main.java
├── Bank.java
├── Customer.java
├── Account.java
├── SavingsAccount.java
└── CurrentAccount.java

How to Run

1. Clone this repository.
2. Open the project in your preferred Java IDE.
3. Run "Main.java".
